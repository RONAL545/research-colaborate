# Agente autenticación — feature/auth
Implementa contratos auth y perfil en app/modules/auth. Usa SQLAlchemy, migración 0002_auth desde 0001_bootstrap, hashes Argon2 y JWT con vencimiento y algoritmo fijo. Sustituye únicamente el cuerpo/imports necesarios de get_current_user en core/dependencies.py conservando su identidad pública. Persiste tokens de verificación hasheados, con caducidad y consumo único; reenvío genérico y dominios permitidos configurables. Define un adaptador de correo inyectable con buzón de pruebas; no devolver tokens en la API ni registrarlos en producción. Sin proveedor configurado, documentar bloqueo del envío real. Prueba registro duplicado, dominio rechazado, expiración/reuso/reenvío, login, tokens inválidos, perfil propio y roles no escalables. No modificar schemas, routers ajenos ni main.py. Entrega commit y evidencia; no integres en dev.
